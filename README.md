# 0701-SkillHub

Personal skill collection hub for Claude Code / Codex skills.

## Structure

```
SkillHub/
├── 01-CreatedSkills/    # 自研 Skills（原创）
├── 02-CollectedSkills/  # 收集的 Skills（GitHub 开源）
└── 03-SkillMap/         # 技能地图（分类/映射/规划）
```

## Usage

- **Created Skills** — skills I built, each with SKILL.md + scripts
- **Collected Skills** — curated open-source skills with source links
- **Skill Map** — how skills map to workflows (research, LaTeX, data, etc.)

See [CONTRIBUTING.md](CONTRIBUTING.md) for conventions.
