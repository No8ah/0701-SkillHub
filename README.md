# 0701-SkillHub

Personal skill collection hub for Claude Code / Codex.

## Structure

```
SkillHub/
├── 01-CreatedSkills/    # 自研 Skills（按领域分类）
│   ├── 01-LaTeX/        # LaTeX 工具链
│   ├── 02-Research/     # 科研辅助
│   ├── 03-Coding/       # 编码/工作流
│   ├── 04-Visualization/# 可视化
│   └── 08-Workflow/     # 部署/同步
├── 02-CollectedSkills/  # 收集的开源 Skills（含上游链接）
└── 03-SkillMap/         # 技能地图（分类/平台/工作流/全量）
```

## Naming Convention

`<DomainID><SkillID>-<FunctionName>`

| Domain | ID | 示例 |
|--------|:--:|------|
| LaTeX | 01xx | 0101-ChapterLogicFormatter |
| Research | 02xx | 0201-RigorousMathAnswer |
| Coding | 03xx | 0303-GitHubInboxManager |
| Visualization | 04xx | 0401-DrawioChartReconstructor |
| Workflow | 08xx | 0801-PersonalWebsiteDeployment |

See [01-CreatedSkills/README.md](01-CreatedSkills/README.md) and
[03-SkillMap/README.md](03-SkillMap/README.md).
