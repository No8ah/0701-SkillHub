# Rigorous Math Answer

## Core Rules

- 不输出 LaTeX 源码；只输出可读数学表达。
- 所有回答必须分层、编号、结构化。
- 推导必须 Step by Step，不得省略关键步骤。
- 每个结论都要标注依据：定义 / 性质 / 定理 / 已知条件 / 上一步结论。
- 术语、符号、编号、模板在同一题内必须一致。
- 不得虚构出处；无法精确定位时必须说明原因。
- 若未指定教材，必须原样加一句：
  "以下章节位置按通用教材体系给出，具体请以你的教材目录为准。"
- 优先使用用户提供的本地文件、讲义、PPT作为出处来源。

## Hard Constraint: 仅三种范式

所有知识点标题与归类，必须严格落入以下三类，不得扩展第四类：

1. 定义 - *
2. 性质 - ...的性质(*) - *
3. 定理 - ...

补充约束：
- 不使用“命题”“推论”“引理”作为一级范式名。
- 如教材原文是“命题/引理/推论”，在输出中统一映射到“性质”或“定理”。
- "性质"标题必须带编号：`...的性质(1) - ...`。

## Naming & Mapping Rules

- 定义类：
  - 标题：`定义 - X`
  - 内容段第4项写“定义”。
- 性质类：
  - 标题：`性质 - X的性质(k) - Y`
  - 内容段第4项写“性质”。
- 定理类：
  - 标题：`定理 - X`
  - 内容段第4项写“定理”。

当来源为“S.A.T.”或“iff”语句时：
- 若用于对象命名（是什么）：归“定义”。
- 若用于对象已定义后的判别/等价结论：归“性质”或“定理”。

## Default Workflow

用户未指定更窄格式时，按以下顺序回答：

1. 课本出处
2. 前置严格数学定义体系
3. 思路
4. 严格推导
5. 总结考点与题型方法

若用户只问“题目命名/知识点速查”，使用 Format D。

## Source Labels

凡提到：考点、定义、性质、定理、方法、模板，均标注出处到最细层：

- 教材：第X章 → 第X节 → 第X小节
- 讲义/PPT：第X讲 → 第X页 或 PPT 第X页
- 未指定教材：必须加通用出处提示句（见 Core Rules）

禁止使用模糊出处，如：
- “在线性代数里”
- “前面学过”
- “高数某处”

## Format A: 定义 / 性质 / 定理（知识点说明）

适用问题：
- 给出定义条件和内容
- 给出定理条件和结论
- 说明某个性质

模板：

1. 课本出处
- 课本中的位置：
- 第X章：
- 第X节：
- 第X小节：
- 若无法精确定位：说明原因

2. 设
- 给出对象、空间、变量、函数、背景条件。

3. 如果
- 给出成立所需条件。

4. 定义 / 性质 / 定理
- 只写三范式之一。
- 定理结论可分点列出。

5. 其中
- 逐一解释符号、表达式、参数、空间。

6. 依据说明
- 依赖哪些前置概念。
- 常用于解决什么问题。

## Format B: 严格推导 / 证明

适用问题：
- Step by Step 严格推导
- 证明一句话
- 详细推导一步

模板：

1. 课本出处
- 本题相关知识点在课本中的位置（可多条）。

2. 思路
- 推导目标
- 已知条件
- 要调用的定义/性质/定理
- 方法选择原因

3. 具体推导过程

Step 1：
- 本步目标：
- 推导：
- 依据：

Step 2：
- 本步目标：
- 推导：
- 依据：

（持续到结论成立，不得跳步）

4. 结论
- 给出最终结论。
- 说明如何由前面步骤得到。

5. 易错点 / 跳步提醒
- 指出常见漏条件、错用结论、符号混乱点。

## Format C: 题目考点 / 知识点分析

适用问题：
- 这题考什么
- 对应哪个知识点
- 在课本哪里
- 需要哪些前置定义

模板：

1. 题目考点在课本中的位置
- 第X章
- 第X节
- 第X小节
- 讲义/PPT定位（如有）

2. 前置严格数学定义体系
- 逐条列出，且每条必须使用：
  - 课本出处
  - 设
  - 如果
  - 定义/性质/定理（三选一）
  - 其中

3. 考点思路
- 本质考察点
- 识别标志
- 解题突破口
- 优先调用顺序
- 通用模板

4. 本题与常见题型的联系
- 所属题型
- 与相近题型区别
- 为什么此题优先用该方法

## Format D: 题目命名 + 知识点速查

适用问题：
- 这道题叫什么
- 给个目录标题
- 简要知识点

模板：

1. 题目命名
- 1个首选标题
- 必要时给1个备选

2. 知识点速查
- 3-6个核心标签

3. 本地定位
- 文件路径 + 行定位
- 行区间不够时说明需补充的范围

4. 可直接粘贴的目录标题（可选）
- 给1条简洁标题文本（非 LaTeX 源码）

约束：
- 保持简洁
- 用户未要求证明时，不展开推导

## Quality Checklist

提交前检查：
- 无 LaTeX 源码输出。
- 每个关键结论都有依据。
- 前提条件未遗漏。
- 仅使用三种范式：定义 / 性质 / 定理。
- 出处标注到“章-节-小节”或“讲-页”。
- 未指定教材时已加通用出处提示句。
- 回答可反向支持“从题目定位到知识点与出处”。
