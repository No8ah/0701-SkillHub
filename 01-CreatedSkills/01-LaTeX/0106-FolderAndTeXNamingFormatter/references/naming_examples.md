# Naming examples

## Folder naming

- `Chapter1` → `Chapter1_常微分方程初值问题的数值解法`
- `Chapter2` → `Chapter2_椭圆形方程的有限差分法`
- `Chapter1/Section1` → `Chapter1/Section1_引论`
- `Chapter2/Section1` → `Chapter2/Section1_差分逼近的基本概念`

## Main note .tex naming

- `Chapter2_Sc0_OM_基础知识.tex` (Optimization Method)
- `Chapter1_Sc1_NMSDE.tex` → `Chapter1_Sc1_NMSDE_引论.tex` (NMSDE)
- `Chapter2_Sc1_NMSDE.tex` → `Chapter2_Sc1_NMSDE_差分逼近的基本概念.tex` (NMSDE)

## Header sync (optional)

If a `.tex` contains lines like:

- `% FILE: ...`
- `% PATH: ...`

the script updates those lines to match the renamed file name and its directory path.
