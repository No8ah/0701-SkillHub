# Contributing

## Adding a skill

### Created Skills (`01-CreatedSkills/`)

```
01-CreatedSkills/<skill-name>/
├── SKILL.md
├── scripts/     # (optional)
└── references/  # (optional)
```

### Collected Skills (`02-CollectedSkills/`)

Create a folder with a README pointing to the upstream repo:

```
02-CollectedSkills/<skill-name>/
└── README.md    # source URL + notes
```

### Skill Map (`03-SkillMap/`)

Update `map.md` with the skill → workflow mapping.
